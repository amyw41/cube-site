# Cube Site

A modern web platform built with Next.js for showcasing Cube projects, opportunities, and information about the team.

## 🚀 Tech Stack

- Next.js
- TypeScript
- React
- Tailwind CSS
- Node.js

## 📁 Project Structure
app/
page.tsx → Landing page

about/
page.tsx → About page

projects/
page.tsx → Projects listing page
[id]/
page.tsx → Individual project page (dynamic route)

opportunities/
page.tsx → Opportunities page

## 🧠 Key Features

- Landing page introducing Cube
- Projects page showcasing all projects
- Dynamic project pages for each individual project
- Opportunities page for roles, events, or involvement
- About page for team and mission information
